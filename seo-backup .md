Saya ingin melakukan optimasi SEO menyeluruh untuk website ini agar ketika pengguna mengetik nama website/perusahaan di Google, website muncul di halaman pertama dan sebisa mungkin berada di posisi paling atas.

Nama website/perusahaan:
[nama website : Absensi Golan]
[nama perusahaan : PT. Golan Digital Kreatif]

Domain website:
[ISI DOMAIN WEBSITE]

Target lokasi:
[Tegal Alur, Kalideres, Jakarta Barat, DKI Jakarta, Indonesia]

Target pengguna:
[seluruh karyawam PT. Golan dari manajer, hrd, karyawan, hingga magang]

Teknologi website:
Angular pada frontend dan [ISI BACKEND/DATABASE jika diketahui].

Tujuan utama:

1. Website dapat ditemukan dan diindeks oleh Google.
2. Saat orang mencari nama brand/perusahaan, website muncul di hasil pencarian Google.
3. Website memiliki peluang besar muncul di posisi pertama untuk kata kunci brand.
4. Website juga memiliki peringkat baik untuk kata kunci yang relevan dengan layanan/produk.
5. Website cepat, aman, mobile-friendly, dan mudah dipahami mesin pencari.

Kerjakan audit dan implementasi SEO secara menyeluruh dengan ketentuan berikut.

A. Audit awal website

Periksa seluruh struktur project dan identifikasi:

- Halaman utama dan halaman penting.
- Routing Angular.
- Struktur heading pada setiap halaman.
- Title dan meta description.
- Penggunaan tag canonical.
- Status indexability setiap halaman.
- Link internal dan link eksternal.
- Gambar yang belum memiliki alt text.
- URL yang tidak SEO-friendly.
- Halaman duplikat.
- Broken link.
- Redirect yang salah.
- Error 404.
- Masalah rendering Angular untuk crawler.
- Masalah loading data melalui API.
- Masalah mobile responsiveness.
- Masalah kecepatan website.
- Masalah keamanan HTTPS.
- File robots.txt dan sitemap.xml.
- Data terstruktur/schema markup.
- Potensi masalah pada Core Web Vitals.

Jangan mengubah fungsi utama aplikasi, sistem login, API, database, maupun alur bisnis yang sudah berjalan.

B. Optimasi SEO teknis

Implementasikan hal-hal berikut:

1. Pastikan website dapat diakses menggunakan HTTPS.
2. Buat atau perbaiki file robots.txt.
3. Buat sitemap.xml yang valid dan berisi halaman publik yang penting.
4. Pastikan halaman private seperti login, dashboard, admin, API, dan halaman internal tidak diindeks Google.
5. Tambahkan canonical URL pada semua halaman publik.
6. Pastikan setiap halaman memiliki URL yang unik dan SEO-friendly.
7. Atur redirect dari www ke non-www atau sebaliknya secara konsisten.
8. Pastikan tidak ada mixed content.
9. Perbaiki broken link dan halaman 404.
10. Tambahkan halaman 404 yang informatif dan memiliki link kembali ke halaman utama.
11. Pastikan website dapat dirender dengan baik oleh Googlebot.
12. Jika diperlukan, gunakan Angular SSR atau prerendering untuk halaman publik agar konten utama tersedia dalam HTML.
13. Pastikan konten penting tidak hanya muncul setelah interaksi JavaScript.
14. Optimalkan struktur internal linking.
15. Gunakan breadcrumb untuk halaman yang memiliki struktur bertingkat.
16. Pastikan website mobile-friendly.
17. Optimalkan Core Web Vitals:

- Largest Contentful Paint
- Interaction to Next Paint
- Cumulative Layout Shift

18. Kurangi JavaScript, CSS, font, dan library yang tidak diperlukan.
19. Aktifkan lazy loading untuk gambar dan komponen yang tidak langsung terlihat.
20. Kompres gambar menggunakan format WebP atau AVIF jika memungkinkan.
21. Tambahkan width dan height pada gambar untuk mencegah layout shift.
22. Gunakan caching dan compression pada server.
23. Optimalkan ukuran bundle Angular.
24. Pastikan loading halaman utama secepat mungkin.

C. Optimasi SEO on-page

Untuk setiap halaman publik:

1. Buat title unik dengan panjang ideal dan mengandung nama brand.
2. Buat meta description yang menarik dan relevan.
3. Gunakan satu H1 utama pada setiap halaman.
4. Susun heading H2 dan H3 secara hierarkis.
5. Masukkan keyword secara natural, jangan melakukan keyword stuffing.
6. Buat konten yang jelas, informatif, dan mudah dibaca.
7. Tambahkan alt text deskriptif pada semua gambar.
8. Gunakan nama file gambar yang relevan.
9. Tambahkan Open Graph meta tag untuk Facebook, WhatsApp, dan media sosial.
10. Tambahkan Twitter Card meta tag.
11. Tambahkan favicon dan web app manifest jika diperlukan.
12. Pastikan nama brand ditulis secara konsisten di seluruh website.
13. Tambahkan alamat, email, nomor telepon, jam operasional, dan media sosial jika relevan.
14. Buat call-to-action yang jelas.
15. Tambahkan internal link ke halaman yang relevan.

Gunakan pola title seperti:

- “Nama Brand – Deskripsi Layanan Utama”
- “Tentang Nama Brand – Profil Perusahaan”
- “Kontak Nama Brand – Alamat dan Informasi Kontak”

Gunakan pola meta description seperti:

“[Nama Brand] adalah [jenis perusahaan/layanan] yang menyediakan [layanan utama] untuk [target pengguna] di [lokasi]. Kunjungi website resmi kami untuk informasi selengkapnya.”

D. Optimasi khusus pencarian nama brand

Fokus utama adalah agar website resmi muncul ketika pengguna mencari nama brand/perusahaan.

Implementasikan:

1. Pastikan nama brand tampil jelas pada:
   - Title halaman utama.
   - H1 halaman utama.
   - Konten halaman utama.
   - Footer.
   - Logo alt text.
   - Meta description.
   - Open Graph title.
2. Buat halaman “Tentang Kami” yang menjelaskan identitas perusahaan.
3. Buat halaman “Kontak” dengan informasi resmi perusahaan.
4. Gunakan schema Organization atau LocalBusiness.
5. Tambahkan logo resmi, URL resmi, nomor telepon, email, alamat, dan akun media sosial.
6. Gunakan nama brand yang sama pada seluruh platform online.
7. Pastikan Google tidak menemukan versi website yang berbeda atau duplikat.
8. Buat profil Google Business Profile jika bisnis memiliki lokasi fisik.
9. Hubungkan website dengan Google Search Console dan Google Analytics.
10. Dapatkan backlink berkualitas dari website resmi, direktori bisnis, media sosial, partner, atau website yang relevan.
11. Buat konten yang menyebutkan brand secara alami dan informatif.
12. Hindari backlink spam, keyword stuffing, cloaking, konten duplikat, dan teknik black-hat SEO.

E. Schema markup

Tambahkan schema.org yang sesuai, minimal:

1. Organization atau LocalBusiness.
2. WebSite.
3. WebPage.
4. BreadcrumbList jika digunakan.
5. FAQPage hanya jika halaman benar-benar memiliki FAQ.
6. SoftwareApplication jika website merupakan aplikasi/software.

Schema harus valid, tidak boleh berisi data palsu, dan disesuaikan dengan informasi sebenarnya dari website.

3. Layanan/Produk:
   - Satu halaman untuk setiap layanan utama.
   - Deskripsi manfaat.
   - Target pengguna.
   - FAQ.
4. Kontak:
   - Alamat.
   - Email.
   - Nomor telepon.
   - Peta.
   - Jam operasional.
5. Blog atau artikel:
   - Artikel yang menjawab kebutuhan pengguna.
   - Keyword relevan.
   - Konten original.
   - Internal link ke layanan.

Sebelum membuat konten, tentukan:

- Keyword utama.
- Keyword turunan.
- Search intent.
- Target halaman.
- Title.
- Meta description.
- H1.
- Outline konten.
- Internal link yang disarankan.
